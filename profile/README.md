# Constellation Works

**Separate repos, one front door.**

We build local-first tools for AI-assisted engineering and reproducible research. Each project stands on its own, with its own repository, history, and release cadence.

Start with **[Orbit](https://github.com/constellation-works/orbit)** — durable, intent-tracked project management for AI coding agents. Turn work into tasks, keep a record of what happened, and carry progress across sessions.

### How we build

- **Local-first.** Work on hardware you own, against repositories you control.
- **Traceable work.** Keep intent, changes, and evidence connected.
- **Independent projects.** Use the pieces that fit your work.
